# CIEBP – Leitor de Código de Barras

Aplicativo desenvolvido em Flutter como ferramenta de apoio às aulas de Educação Financeira no ambiente escolar. A proposta é aproximar conceitos financeiros do cotidiano dos estudantes por meio da simulação de uma experiência de compra.

## Funcionalidades

- Leitura de códigos de barras utilizando a câmera do dispositivo.
- Identificação e registro de produtos.
- Adição de produtos ao carrinho de compras.
- Cálculo do valor total da compra.
- Simulação do fechamento do carrinho.

## Tecnologias utilizadas

- **Flutter:** desenvolvimento da aplicação.
- **Dart:** linguagem de programação.
- **Mobile Scanner:** leitura de códigos de barras pela câmera.
- **Path Provider:** acesso a diretórios de armazenamento do dispositivo.
- **Intl:** formatação de valores e informações.

## Objetivo educacional

O projeto busca oferecer um recurso tecnológico para trabalhar conceitos de Educação Financeira, permitindo explorar situações práticas de consumo, comparação de preços e planejamento de compras.

## Execução do projeto

1. Clone este repositório.
2. Instale as dependências:

   ```bash
   flutter pub get
   ```

3. Execute a aplicação:

   ```bash
   flutter run
   ```
